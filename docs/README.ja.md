# Gear Composer インポートデータ
HIT: The World の提供画像から読み取った非公式カタログです。
## 読み込み
[import.json](../games/hit2/ja/import.json) を使用します。現行アプリのJSON読み込みにはProが必要です。
revision **47**：**457件・80属性・2461能力値**。
内訳は通常装備365件、カード32件、ペット38件、闘魂22件。画像根拠のない59件を除外し、主画像457枚と各アイテムが1対1で対応し、エッダの化身の追加画像1枚でも既存6能力値の一致を確認しています。名前だけの項目はありません。
## 確認状態
画像457枚の表示数値は読取確認済みで、457件すべて計算可能です。種類ごとに一つのアイテムとして扱います。値の換算・推測・補完はしていません。表示値を初期値・最大値と断定するものではありません。
## 使用上の注意
- カード4枚、ペット1体、闘魂1体。武器は共通1枠です。
- 同種カード・対象リング固有の重複禁止は現行アプリで自動強制されません。武器の対応クラスは、セット作成時にクラスを選ぶと絞り込まれます。指定なしではすべてのクラスを対象に検索します。
- 画像の掲載値を初期値・最大値と断定せず、百分率は表示値の単純加算です。ゲームの最終ダメージ式や条件付き効果を再現しません。
- 倉庫・分解可否、下部二つのアイコン値、コレクションは収録対象外。パワーストーンポイントは参考情報で計算対象外です。
- 通常装備は基本的に英雄以上ですが、提供画像にある希少以下の品も含みます。ランクは提供者の色対応説明に基づきます。
## 旧データからの更新
闘騎はrevision41、画像根拠のない項目はrevision42でカタログから除外しました。ただし既存カタログへの再インポートは追加マージのため、除外項目や所持情報・保存セット参照を自動削除しません。個人データをバックアップしてから必要な整理を行い、件数を合わせるためゲーム全体を削除しないでください。画像で確認した既存項目のIDは維持しています。
## 公開範囲
Git管理対象はルートREADME、この説明、import.json、.gitignoreのみ。画像・出典索引・確認一覧・検証スクリプトはGit対象外です。旧資料は復元可能なローカルバックアップへ退避しています。
## 権利
公式提供・公認のデータではありません。権利は各権利者に帰属します。ゲーム画像や長文の説明転載は公開対象に含めません。再配布時は適用規約と権利条件を確認してください。

## レアリティの表示色
一般：灰、高級：緑、希少：青、英雄：紫、古代：黄、伝説：橙、不滅：赤。各ランクの提供画像で確認した色に合わせた表示用配色です。公式の厳密なRGB値ではありません。アプリは背景に合わせて文字色のコントラストを調整します。更新JSONを再インポートするとランク色が反映されます。個別アイテム色を設定している場合はそちらが優先されます。


## 装備先の表示順
各装備先に任意の `displayOrder` を追加しました。対応するアプリでは次の順で表示します。未対応の旧版アプリでは先にアプリを更新してください。

武器 → ヘルム → 上衣 → グローブ → 下衣 → 靴 → マント → ネックレス → リング → ブレスレット → ベルト → 勲章 → アミュレッタ → カンパネラ → ペット → 闘魂 → カード


## 対応クラス（revision 46）
クラスを `game.classes` に定義し、対応が限定される141件の武器には `classIds` を設定しました。既存metadataに記録されていた対応クラスを移し、能力値・アイテムIDは変更していません。各アイテムは複数クラスを指定できます。`classIds` の省略・空配列は全クラス対応です。共通装備・ペット・闘魂・カードはクラス未設定としています。

クラスはタグとは独立しています。更新したアプリでJSONを再インポートしてください。セットのクラスは初期値「指定なし」で、クラス選択後はそのクラス対応と全クラス対応のアイテムが候補になります。既存の保存セットの検索条件は自動変更しません。


## レアリティの高さ（revision 47）
各ランクに `rank` を追加しました。大きい数ほど高レアリティです。一般1・高級2・希少3・英雄4・古代5・伝説6・不滅7です。アイテム一覧では同じ装備先の中で高レアリティ順、置き換え候補では指定属性の値が大きい順（同じ値は高レアリティ順）に表示します。指定属性がない候補は、属性がある候補の後で高レアリティ順になります。従来のhit2データも対応アプリではこの順序で表示します。アイテムID・能力値・所持情報は変更しません。
